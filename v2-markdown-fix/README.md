# v2 — нормальное отображение Markdown в Telegram

Правит главную проблему [v1](../v1-basic): Claude Code по умолчанию отвечает в Markdown (`**жирный**`, `# заголовки`, списки), а Telegram без специальной обработки показывает эти символы буквально, а не как форматирование.

## Что изменилось относительно v1

- Ответ Claude теперь прогоняется через библиотеку [`telegramify-markdown`](https://pypi.org/project/telegramify-markdown/), которая конвертирует обычный Markdown в Telegram-совместимый **MarkdownV2** (с корректным экранированием спецсимволов).
- Отправка идёт с `parse_mode=MarkdownV2`, поэтому жирный текст, курсив, списки и блоки кода теперь реально отображаются как форматирование, а не как сырые звёздочки/решётки.
- Если конвертация или отправка вдруг падает с ошибкой — есть отказоустойчивый откат: сообщение всё равно уходит, но обычным текстом, чтобы бот не оставался немым.
- Небольшая правка: подпись к распознанному голосовому сообщению больше не оборачивается в markdown-курсив (`_текст_`), чтобы не зависеть от парсинга на этом шаге.

## Известная проблема этой версии

Разбивка длинных сообщений на части всё ещё делается **по количеству символов**, без учёта структуры markdown. Если разрез попадает точно посередине блока кода (``` ```), получившийся кусок после конвертации в MarkdownV2 имеет незакрытый тройной бэктик — Telegram отклоняет такое сообщение целиком, и бот откатывается на отправку **всего ответа** сырым текстом (со звёздочками и решётками). Эта проблема исправлена в [v3](../v3-persona-typing), где разбивка учитывает границы блоков кода.

## Что умеет (не изменилось относительно v1)

- Текст, голосовые (через локальный `faster-whisper`), фото — как в v1.
- Одна сессия/история на Telegram-чат, `/reset` для сброса.
- Whitelist по `ALLOWED_USER_IDS`.
- Индикатор «печатает…» — по-прежнему разовый, гаснет через ~5 секунд при долгом ответе (это тоже исправлено в v3).

## Файлы

Та же структура, что и в v1, плюс новая зависимость `telegramify-markdown` в `requirements.txt`.

## Установка

Аналогично v1 — см. README версии v1 за подробностями по установке Node.js, Claude Code, systemd-сервиса и авторизации по подписке (`claude setup-token`). Дополнительно после `pip3 install -r requirements.txt` подтянется `telegramify-markdown`.
