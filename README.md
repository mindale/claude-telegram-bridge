# claude-telegram-bridge

Мост между **Claude Code** (запущенным под вашей личной подпиской, без Anthropic API) и Telegram-ботом: пишете боту текстом, голосом или фото — получаете ответ от Claude, с сохранением истории разговора на сервере (VPS).

Здесь собраны все версии бота по мере развития — от самой простой до текущей, многофункциональной. Каждая версия лежит в своей папке с полным исходным кодом, файлами конфигурации и **подробным README**, который объясняет, что изменилось и почему.

## Версии

| Версия | Папка | Коротко |
|---|---|---|
| v1 | [`v1-basic`](./v1-basic) | Базовый мост: текст, голос (faster-whisper), фото, память разговора на чат, `/reset`. Без обработки Markdown. |
| v2 | [`v2-markdown-fix`](./v2-markdown-fix) | Добавлена конвертация Markdown → Telegram MarkdownV2 (`telegramify-markdown`), чтобы `**жирный**` и `# заголовки` отображались как форматирование, а не сырой текст. |
| v3 | [`v3-persona-typing`](./v3-persona-typing) | Дружеский человеческий тон общения, живой индикатор «печатает…» (не гаснет, пока Claude думает), исправлена разбивка длинных сообщений — код-блоки больше не рвутся пополам. |
| v4 | [`v4-multichat`](./v4-multichat) | **Текущая версия.** Несколько именованных веток разговора в одном Telegram-чате (`/newchat`, `/switch`, `/chats`, `/rename`, `/delchat`), свой стиль общения на ветку (`/style`), подключаемые скиллы из `skills.json` (`/skills`, `/addskill`, `/removeskill`). |

Рекомендуется использовать **v4** — она включает в себя все улучшения предыдущих версий. Остальные версии оставлены как история разработки и для тех, кому не нужна сложность многочатовости.

## Общая архитектура

Во всех версиях:

- Bot написан на Python (aiogram 3, asyncio).
- Claude вызывается в headless-режиме: `claude -p "<текст>" --output-format json --resume <session_id>`.
- Авторизация — через `claude setup-token` (личная подписка), без API-ключа.
- Голосовые сообщения распознаются полностью локально (`faster-whisper`), без сторонних API.
- У каждого Telegram-чата (а с v4 — у каждой ветки внутри чата) своя рабочая директория на диске, так что сессии Claude Code не пересекаются между разными разговорами.
- Установка — через `install_fedora.sh` (Node.js, Claude Code CLI, Python, ffmpeg) и systemd-юнит `claude-bridge.service` для работы бота в фоне.

## С чего начать

Если разворачиваете бота впервые — начните с README версии [v4](./v4-multichat), она самая полная. README версий v1–v3 полезны, если хочется понять историю развития или пошагово разобраться, как решалась каждая проблема (сломанный Markdown, индикатор печати, разбивка сообщений).
