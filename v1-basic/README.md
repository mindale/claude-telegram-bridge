# v1 — базовая версия

Самая первая рабочая версия моста между Telegram и Claude Code. Минимальный набор функций, без украшательств — отсюда и начали.

## Что умеет

- **Текстовые сообщения** — пересылаются в `claude -p "<текст>"` в режиме print (headless), ответ приходит обратно в Telegram.
- **Голосовые сообщения** — скачиваются как `.ogg`, конвертируются в `.wav` через `ffmpeg`, распознаются локально моделью `faster-whisper` (без внешних API), распознанный текст уходит в Claude как обычное сообщение.
- **Фото** — сохраняются в рабочую директорию чата, Claude получает подпись + путь к файлу и может посмотреть на изображение своим встроенным Read-инструментом.
- **Память разговора** — у каждого Telegram-чата своя рабочая директория (`sessions/<chat_id>/`), в ней Claude Code хранит свою сессию через `--resume <session_id>`. Один чат = один непрерывный разговор.
- **Whitelist по `ALLOWED_USER_IDS`** — бот отвечает только заданным Telegram id, всем остальным — отказ.
- **`/reset`** — сбросить историю разговора и начать заново.

## Известные ограничения этой версии

- Ответы Claude отправляются как обычный текст **без обработки markdown** — если Claude отвечает с `**жирным**`, заголовками `#` или списками, в Telegram это видно как сырые символы (звёздочки, решётки), а не отформатированный текст. Это исправлено в [v2](../v2-markdown-fix).
- Один чат — один непрерывный разговор, без возможности вести параллельно несколько тем (это добавлено в [v4](../v4-multichat)).
- Стиль общения Claude — стандартный (никакой персоны/тона не задаётся).
- Индикатор «печатает…» отправляется один раз перед вызовом Claude и гаснет примерно через 5 секунд по ограничению Telegram, если ответ готовится дольше.

## Файлы

- `bot.py` — сам бот (aiogram 3, asyncio).
- `requirements.txt` — Python-зависимости.
- `.env.example` — шаблон конфигурации, скопировать в `.env` и заполнить.
- `install_fedora.sh` — установка Node.js, Claude Code CLI и системных зависимостей на Fedora/RHEL-подобной VPS.
- `claude-bridge.service` — systemd-юнит для запуска бота как фоновой службы.

## Установка

1. На сервере (Fedora): `bash install_fedora.sh` — поставит Node.js, `@anthropic-ai/claude-code`, Python3/pip, ffmpeg.
2. Авторизация Claude Code **по вашей подписке, без API-ключа**: на компьютере с браузером выполните `claude setup-token`, полученный токен пропишите на сервере:
   ```
   echo 'export CLAUDE_CODE_OAUTH_TOKEN="..."' >> ~/.bashrc && source ~/.bashrc
   ```
3. `pip3 install -r requirements.txt`
4. `cp .env.example .env` и заполните `TELEGRAM_BOT_TOKEN` (от @BotFather) и `ALLOWED_USER_IDS` (свой id от @userinfobot).
5. Запуск напрямую: `python3 bot.py`, либо как сервис — см. `claude-bridge.service` (поправьте пути под ваше расположение, затем `systemctl daemon-reload && systemctl enable --now claude-bridge`).

## Важно про безопасность

Claude Code по умолчанию спрашивает подтверждение перед использованием инструментов (запись файлов, выполнение команд). В headless-режиме через бота такие запросы просто зависают. Если нужно, чтобы Claude мог действовать без вопросов — добавьте в `.env`:

```
CLAUDE_EXTRA_ARGS=--dangerously-skip-permissions
```

Это даёт агенту полный доступ к серверу без подтверждений — используйте только если бот доступен исключительно вам (`ALLOWED_USER_IDS` строго ваш id).
